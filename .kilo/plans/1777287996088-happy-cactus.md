# Codebase Understanding Plan

## Project Overview
This is an Angular 9 application (ClientApp) that appears to be a BSS/SSP (Business Support System/Subscription Service Portal) frontend. The application uses Angular Material and various third-party libraries for functionality like mapping, file handling, and UI components.

## Key Observations

### Project Structure
- Standard Angular CLI project structure
- `src/app` contains all application modules and components
- Feature-based organization with separate modules for different functionalities
- Uses lazy loading for feature modules via `loadChildren` in routing

### Core Configuration Files
- `package.json`: Shows Angular 9.1.0 with Angular Material 9.2.0
- Dependencies include: `@angular/material`, `@ng-bootstrap/ng-bootstrap`, `leaflet`, `highcharts`, `quill`, `rxjs`, etc.
- Development dependencies include Jasmine, Karma, Protractor for testing

### Routing Structure (`app-routing.module.ts`)
- Main routes:
  - Empty path redirects to 'home'
  - Auth routes: login, sign-up, verify-otp, forgot-password
  - GIS module: `/gis/map` 
  - Main application layout with auth-protected routes
- Feature modules loaded lazily:
  - Master data, appendix, inception report, PBTE, ROSI, etc.
  - TSP (Trainee Service Provider) modules
  - Reports, dashboard, notifications
  - Many others including workflow management, payment, etc.

### Services and Shared Components
- `CommonSrvService`: Appears to be a major service (large file size suggests significant functionality)
- `AppConfigService`: Handles application configuration loading
- `AuthService` and `AuthGuardService`: Authentication and authorization
- `DialogueService`: For dialogs/popups
- `SharedModule`: Likely contains common components, pipes, directives
- Custom components in `custom-components` directory for various UI elements

### Security
- Uses JWT authentication via `AuthInterceptor`
- Route protection via `AuthGuardService`
- Session timeout handling via `BnNgIdleService` (1 hour timeout)

### Styling
- Uses SCSS for styling (`styles.scss`, component-specific SCSS files)
- Angular Material theming
